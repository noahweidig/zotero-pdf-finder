Install

  1. Download zotpdf.xpi from the latest release.
    In Firefox, right-click the link and choose Save Link As…. A plain click makes Firefox try to install it as a Firefox add-on.
  2. In Zotero, open Tools → Plugins.
  3. Drag the .xpi into that window, or click the gear ⚙ → Install Plugin From File… and pick it.

No restart is needed. ZotPDF appears under Tools → Plugins and as a ZotPDF submenu in the item right-click menu and the Tools menu. Zotero checks for new versions automatically.

Coming from OpenAlex PDF Finder or FullVahti

ZotPDF replaces both and has its own add-on ID (zotpdf@noahweidig). Uninstall the old ones in Tools → Plugins first, or you will see duplicate menus.

Settings do not carry over: ZotPDF stores its own under extensions.zotero.zotpdf.*. Re-enter your email and OpenAlex key once in Settings. Existing fulltext:*, retraction:* and citation:* tags stay valid.

Build from source

git clone {{repo}}.git
cd ZotPDF
npm run lint && npm test
npm run build      # writes build/zotpdf-<version>.xpi and build/zotpdf.xpi
