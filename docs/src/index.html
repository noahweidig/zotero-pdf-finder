Find the PDFs. Catch the retractions. Fix the citations.

ZotPDF is a Zotero plugin for literature reviews. Select references, right-click, and it attaches free legal PDFs, flags retracted papers, and tells you which records have wrong or missing metadata.

Download zotpdf.xpi Install guide

Find PDFs

One pass through Unpaywall, PubMed Central and OpenAlex. Matches by DOI, PMID, arXiv ID or exact title. Each item is tagged fulltext:pdf-found, pdf-missing or check-needed. No notes are created.

Check retractions

Reads PubMed and Crossref, which carries the Retraction Watch database. Catches the mass retractions PubMed doesn't index.

Audit metadata

Compares each record with Crossref and flags missing fields and mismatches. A mismatch often means the wrong DOI is attached. Nothing is edited.

The PDF chain

Already has a PDF?→Unpaywall→PubMed Central OA subset→OpenAlex links→OpenAlex hosted→Publisher page

The first source that returns a real PDF wins. The last two are optional. Details.

One menu

Right-click any reference and choose ZotPDF:

  • Find PDFs
  • Check for retractions
  • Check citation metadata
  • Full check runs all three on the same selection

Tag a whole screening set instead and run the same commands from Tools → ZotPDF. Progress shows in one table per run, with a Cancel button and a result for every item.
