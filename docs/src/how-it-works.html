How it works

The PDF chain

For each item ZotPDF extracts a DOI, PMID and PMCID, then tries sources in order and stops at the first real PDF.

#SourceWhat it needsNotes
0Existing attachmentnothingItem is tagged found and skipped.
1UnpaywallDOITries every open-access location with a direct PDF link, best first.
2PubMed CentralPMID or PMCIDOnly the PMC Open Access Subset through the official OA service, with Europe PMC as a fallback for the same record. PMC pages are never scraped.
3OpenAlex linksDOI, PMID, arXiv ID or titleLocations OpenAlex marks open access with a direct PDF URL. Published versions before accepted before submitted.
4OpenAlex hostedAPI keyOptional. About $0.01 a file, roughly 100 a day free. Tried before step 3 if you turn on "prefer hosted".
5Publisher pagesnoneOptional, on by default. Zotero's own downloader and translators, using your browser session and institutional access. Turn off to stay strictly open access.

Every download is checked: the bytes must start with %PDF- and be between 10 KB and 100 MB. Publisher error pages and login stubs are rejected.

Matching items to OpenAlex

None of thosefilter=title.search:…Normalized titles are identical and years differ by at most 1

Normalization casefolds, strips accents and removes punctuation. A wrong PDF on the wrong reference is worse than none, so near-matches are reported, never attached.

Duplicates and politeness

Items sharing a DOI, PMID or PMCID in one run are fetched once; the others are tagged to match. Every outgoing request is preceded by a short pause (400 ms by default), within NCBI's limit of 3 requests a second without a key. A 429 from OpenAlex triggers a bounded retry.

Cost model

OpenAlex meters its API by credit with a free daily allowance that resets at midnight UTC. Metadata lookups are cheap (a 1,000-reference review uses about 20 requests). Only the optional hosted download costs real credits, and a rejected key degrades to anonymous metadata access instead of failing.
