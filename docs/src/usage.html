Use it

A few references

  1. Select one or more items (Cmd/Ctrl + A selects the whole collection).
  2. Right-click → ZotPDF → Find PDFs, Check for retractions, Check citation metadata, or Full check.
  3. A window lists every item with its result. You can keep working while it runs. Cancel stops after the current item.

The first run asks for a contact email once. The free services behind ZotPDF ask for one.

A whole screening set

  1. Tag your references, for example cite:closer-look. The tag name is set in Settings.
  2. Tools → ZotPDF → Find PDFs for tagged items. The same menu has the retraction and metadata checks.
  3. Filter by the result tags to see what needs attention.

Batches are polite: one item at a time with a pause between requests. 100 items take a few minutes. Runs over 60 items ask before starting.

What you get
