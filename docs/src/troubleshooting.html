Troubleshooting

The ZotPDF menu is missing

Open Tools → Plugins. ZotPDF should be listed and enabled. If it says it's incompatible with your Zotero version, install the latest release. The right-click submenu hides when only notes are selected.

Duplicate menus

Another PDF-finder plugin is installed alongside ZotPDF. Uninstall it in Tools → Plugins.

"OpenAlex rate limit reached"

The free daily allowance is used up (it resets at midnight UTC). Wait, or add a free API key.

"OpenAlex rejected the API key"

Check the key in Settings → ZotPDF and press Test. Metadata lookups continue anonymously; only hosted downloads stop.

Everything comes back "check needed"

Usually a network problem or a blocked host. Make sure api.unpaywall.org, eutils.ncbi.nlm.nih.gov, api.openalex.org and api.crossref.org are reachable.

A publisher returned a page instead of a PDF

That link is rejected automatically and the next source is tried. Publishers that block automated downloads show as "listed N PDF link(s) but none downloaded".

Report a bug

Turn on Help → Debug Output Logging, run the command again, then View Output. Lines starting with [ZotPDF] are ours. Open an issue with them.
